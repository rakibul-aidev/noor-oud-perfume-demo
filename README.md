# Noor & Oud — Concept Demo

Single-file HTML/CSS/JS concept site for an alcohol-free attar/oud perfume brand, built with Claude AI.

Built to demonstrate a design direction and a scroll-scrubbed "pour" animation (GSAP ScrollTrigger) for a client scoping conversation, alongside a scripted AI fragrance-assistant chat mockup.

**This is a demo only** — no backend, payment processing, inventory, or real product data. Not production-ready.

Open `index.html` directly in a browser, or serve the folder with any static file server.
